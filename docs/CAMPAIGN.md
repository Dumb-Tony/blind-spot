## Replaying test solutions (spoilers)

`tests/solutions.json` records each pull as `[left, down, optionalToolId]`, in playfield pixels relative to the launcher at (220,490). The production regression suite replays these launches through the same physics as the game. A successful solver is a feasibility check, not a claim of the minimum possible shot count or a substitute for broad human difficulty testing.
