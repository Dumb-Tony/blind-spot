# Redline Ward and Overgrowth — 0.18

Version 0.18 appends forty levels without changing the IDs or order of the existing 120. Sol’s Breach Charge applies a focused 125-pixel blast to cameras and destructible structure. Niko’s Foam Pod creates a persistent physical body and pushes nearby dynamic objects upward, allowing players to build leverage as well as destroy supports.

All forty new layouts begin stable and have recorded three-star routes. Difficulty grows from two exposed targets through separated towers, layered loads, steel obstructions and six-camera finales. Overgrowth adds mixed arsenals so later solutions can combine foam, charges and stones.

Each installation seeds its fracture variation from its stable level identity. This keeps debris organic while making browser replays and player retries consistent instead of allowing an accumulated random state to change a collapse.

Sol and Niko use a new cohesive two-character, three-pose atlas generated from the established game character style. The production renderer includes distinct launchers, projectiles, trails, ability colors and district palettes for both tools.

Release validation covers 160 exact production routes, 160 accelerated browser pointer replays, six-tool inventory behavior, fixed-step physics, material fracture, floating-object cleanup and 480 varied stress throws.
